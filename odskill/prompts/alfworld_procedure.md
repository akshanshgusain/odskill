## When to Apply
Every ALFWorld household task.

## When NOT to Apply
The episode is already won.

## Instructions
- Copy one admissible action exactly. Do not invent wording.
- Go to a location before you look, open, take, or use anything there.
- Search receptacles one by one. Open a closed receptacle before looking inside.
- Pick up the target before you use an appliance or put the object down.
- Heat with the microwave, cool with the fridge, and clean with the sinkbasin.
- Then go to the destination and put the object where the goal says.
- If an action fails, choose a different admissible action. Do not repeat it.
