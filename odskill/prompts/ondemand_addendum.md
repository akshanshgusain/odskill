Deployment note: the executor does not see skill bodies by default. It sees an index containing only each skill's name and description, mixed with many unrelated skills, and must call load_skill to read one. A skill that is never loaded has no effect. The name, description and 'When to Apply' section therefore decide whether a skill is ever used. You may create or patch skills to improve how reliably they are loaded on the tasks they help, and not loaded on tasks they don't.
