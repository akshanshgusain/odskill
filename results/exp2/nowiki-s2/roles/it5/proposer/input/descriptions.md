look_at_obj_in_light: ALWAYS load for ANY task with look at / examine / inspect / see an object under, with, or in a desklamp or floorlamp (e.g. "look at the alarmclock under the desklamp"). Take the object, go to the lamp, `use` it to turn it on.
pick_and_place: ALWAYS load for plain "put a/some X in/on Y", "place X on Y", or "move X to Y" tasks with ONE object and no heat/cool/clean/lamp/two (e.g. "put a mug on the desk", "put some soap in the cabinet", "put a book on the bed"). Find, take, put. Default skill for simple put tasks.
pick_clean_then_place: ALWAYS load when the task contains "clean", "wash", or "rinse" with an object to be put somewhere (e.g. "put a clean plate in the cabinet", "clean some mug and put it on the desk"). Take object to the sinkbasin, clean it, then place it.
pick_cool_then_place: ALWAYS load when the task contains "cool", "cold", "chill", or "refrigerate" with an object to be put somewhere (e.g. "put a cool apple on the table", "cool some mug and put it in the cabinet"). Take object to the fridge, cool it, then place it.
pick_heat_then_place: ALWAYS load when the task contains "hot", "heat", "warm", or "cook" with an object to be put somewhere (e.g. "put a hot potato on the countertop", "heat some egg and put it on the table"). Take object to the microwave, heat it, then place it.
pick_two_obj_and_place: ALWAYS load when the task says "two", "2", or asks for a pair/multiple of an object (e.g. "put two pillows on the sofa", "find two soapbars and put them in the cabinet"). Place the first, then find and place a second, one at a time.
